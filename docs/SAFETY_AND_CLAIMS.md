# Safety and Claims

## Safe wording

NeuroMark uses real TRIBE v2 predicted cortical activity as an input signal and applies a transparent interpretation layer to generate campaign vectors and response categories.

## Avoid

- Mind reading claims.
- Clinical emotion detection claims.
- Sales guarantee claims.
- Claims that the system measures actual viewer fMRI.

## Disclaimer

This is a research/prototype decision-support system. Outputs are proxy indicators for campaign calibration and should not be interpreted as clinical measurements or guaranteed audience behavior.
